# @wikialisa/styles

> Part of the [WikiAlisa](https://axvn.vn) UI component library.

## Installation

```bash
npm install @wikialisa/styles
# or
yarn add @wikialisa/styles
# or
pnpm add @wikialisa/styles
```

## Usage

```ts
import { version } from "@wikialisa/styles";
```
